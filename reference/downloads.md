# Downloads and how to use them

## Student project

[Download the complete student ZIP](../downloads/microbial-ml-student.zip).

1. Extract the ZIP first.
2. Open `microbial-ml.Rproj` in RStudio.
3. Open `scripts/01-first-run.R` and follow Chapter 1.
4. Work through Chapters 2 and 3.
5. Restart R and run `scripts/worked-example.R` from its first line.

The core scripts need **R only**. No additional student R packages are required. The real-data example needs internet for its first verified download. Keep the project folders together; the scripts use paths relative to the project root.

## For the instructor

This pilot's author source includes executed R notebooks, the canonical R scripts, notebook assembly/execution tools, Jupyter Book configuration and build instructions. The website is a reading interface; live in-page R execution has not been configured.

Book-building dependencies are for the author, not a prerequisite for students. A small RStudio working-session trial with a novice remains useful even after all code and page checks pass.
